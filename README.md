# Cost Estimation System for Function Hall

## Project Overview
This project is a cost estimation system for a function hall developed using Microsoft Excel. It automatically calculates construction costs based on input dimensions such as length, width, and height.

The system provides detailed breakdowns for different construction activities including walls, flooring, plastering, painting, and labour costs. An AutoCAD 3D model is included as a supporting reference for design visualization.

---

## Objective
The main objective of this project is to develop an automated cost estimation tool that reduces manual calculation errors and improves accuracy and efficiency in construction cost estimation.

---

## Features

- Automated calculation of construction costs
- Input-based estimation (Length, Width, Height)
- Separate cost calculation for:
  - Wall construction
  - Flooring
  - Plastering
  - Painting
  - Labour charges
- Clear cost breakdown for each activity
- Easy modification of material rates and dimensions

---

## Working Methodology

1. Enter basic dimensions of the function hall
2. Excel calculates:
   - Wall area
   - Floor area
   - Surface areas for finishing work
3. Apply material rates
4. Calculate labour costs separately
5. Generate final total estimated cost
